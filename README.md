> Guided Breathing Visualizer & Mindfulness Sanctuary

## 📌 Executive Overview
Calming mindfulness portal featuring an animated 4-7-8 / Box breathing visualizer, Web Audio ambient drone synthesizer, session timer ring, and persistent daily mood logging.

## 🚀 How to Run

1. **Clone the repository:**
   ```bash
   git clone https://github.com/royalodi/zenspace.git
   cd zenspace
   ```

2. **Launch locally:**
   Open `index.html` directly or serve via any static HTTP server (`npx serve .`).
